# 체육수업 누가기록

고등학교 체육 수업용 누가기록 앱입니다. 스마트폰에서 한 손으로 쓰고, 인터넷이 끊겨도 동작합니다.
**학생 정보는 각 기기의 브라우저 안에만 저장되고, 어디로도 보내지 않습니다.**

전체 기획은 [`CLAUDE.md`](CLAUDE.md)에 있습니다.

## 진행 상황

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 뼈대 · 오프라인 · PIN 잠금 · 설정 · **명렬 올리기(엑셀/붙여넣기)** | ✅ |
| 2 | 빠른 기록 · 체육부장 · 견학 · 학생별 기록 · 시간표 | ✅ |
| 3 | 타이머 · 스톱워치 | 예정 |
| 4 | PAPS 측정 · 자동 등급 · 나이스 내보내기 | 예정 |
| 5 | 세특 키워드 · 수행평가 · 반 요약 | 예정 |
| 6 | 팀앱 연동 · 백업/복원 · 최종 점검 | 예정 |

## 앱 주소

`https://<GitHub아이디>.github.io/physical-education-/`

처음 한 번만: 저장소 **Settings → Pages → Source** 를 **GitHub Actions** 로 바꿔 주세요.
그 뒤로는 main에 합쳐질 때마다 자동으로 테스트하고 배포합니다 (테스트가 실패하면 배포하지 않음).

## 개발자용

```bash
npm ci          # 설치
npm run dev     # 내 컴퓨터에서 실행 (http://localhost:5173/physical-education-/)
npm run test    # 테스트
npm run build   # 배포용 파일 만들기 (dist/)
```

| 폴더 | 내용 |
|---|---|
| `src/lib/` | 화면과 분리된 계산 코드 (파서 등). 모두 `tests/`에 테스트가 있습니다 |
| `src/db/` | 기기 안 저장소 (IndexedDB / Dexie) |
| `src/pages/` | 화면 |
| `src/data/` | PAPS 공식 기준표 JSON (값을 고치지 않습니다) |
| `references/` | 교사가 준비한 원본 파일 (나이스 샘플은 가명) |

### 알아 둘 점

- **엑셀 라이브러리(SheetJS)**: 최신판은 SheetJS 자체 서버(cdn.sheetjs.com)에서만 받을 수 있는데, 개발 환경에서 이 주소가 막혀 있어 npm에 있는 공식 `xlsx@0.18.5`를 씁니다.
  이 버전에는 "일부러 조작한 엑셀 파일"을 열 때의 알려진 취약점 2건이 있습니다(GHSA-4r6h-8v6p-xvw6, GHSA-5pgg-2g8v-p4x9).
  이 앱은 교사 본인이 고른 파일만 열고 데이터가 기기 밖으로 나가지 않아 위험은 낮지만, 엑셀 코드는 `src/lib/rosterFile.ts` 한 곳에서만 불러오므로 나중에 최신판으로 바꾸기 쉽습니다.
- 학생 실명이 담긴 파일은 커밋하지 마세요. `.gitignore`가 `*.real.*`, `*실명*`, `backup*.json`을 막습니다.
